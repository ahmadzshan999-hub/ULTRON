# ULTRON — Personal AI Workspace

ULTRON is a futuristic personal assistant workspace with a dashboard, a local demo chat interface, task management, and notes.

## What's included
- Responsive dashboard and navigation
- Local demo assistant chat
- Task list with completion and filters
- Notes editor and saved notes
- Browser-based local storage

## Run locally
Open `index.html` in a modern browser.

## Important
This is an early static website preview. The assistant uses local demo responses; it is **not connected to a live AI model**. Tasks and notes are stored in the current browser on the current device.

Never add API keys, passwords, or private credentials to this public repository. A secure backend is needed before connecting a real AI provider.

## Deploy with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will display the published website URL in that section.
